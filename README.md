# Smart Table

**Smart Table** — это гибкий и функциональный компонент таблицы для React, разработанный для эффективного отображения и управления большими объёмами данных. Проект демонстрирует навыки создания сложных пользовательских интерфейсов с продвинутой логикой фильтрации, сортировки и визуализации данных.

---

## О проекте

**Идея проекта:** Создать переиспользуемый компонент "умной" таблицы, который можно легко интегрировать в любое React-приложение для работы с табличными данными. Проект фокусируется на производительности и удобстве использования.

**Решаемая проблема:** Стандартные HTML-таблицы не обладают достаточной гибкостью для современных веб-приложений. Данный проект решает проблемы визуализации больших массивов данных, предоставляя готовые решения для поиска, фильтрации и настройки отображения.

**Ключевая функциональность:**
*   Динамическая загрузка и отображение данных из различных источников
*   Интеллектуальный поиск по всем полям таблицы
*   Многоуровневая фильтрация с возможностью комбинирования условий
*   Сортировка по одному или нескольким столбцам
*   Настраиваемые колонки (ширина, видимость, порядок)
*   Пагинация для работы с большими наборами данных
*   Экспорт данных в популярные форматы (CSV, Excel)
*   Адаптивный дизайн для мобильных устройств

**Стек технологий:**
*   **Frontend:** React 18, TypeScript
*   **Стилизация:** CSS Modules
*   **Управление состоянием:** React Hooks (useState, useMemo, useCallback)
*   **Данные:** Поддержка различных источников (локальные, API)

## ⚙️ Установка и запуск

### Требования
- **Node.js** версии 14 или выше
- **npm** или **yarn**

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/daniloann/smart-table.git
    cd smart-table
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    # или
    yarn install
    ```

3.  **Запустите приложение в режиме разработки:**
    ```bash
    npm start
    # или
    yarn start
    ```
    Откройте [http://localhost:3000](http://localhost:3000), чтобы увидеть результат.

### Сборка для продакшена

```bash
npm run build
# или
yarn build
```

## Как это работает (ключевые сценарии)

1.  **Загрузка данных:** Таблица автоматически загружает данные при монтировании компонента. Поддерживается работа с локальными файлами и внешними API.

2.  **Поиск и фильтрация:** Поле глобального поиска позволяет находить записи по любому полю. Расширенные фильтры дают возможность настраивать условия отбора данных.

3.  **Сортировка:** Клик по заголовку столбца сортирует данные. Повторный клик меняет направление сортировки. Поддерживается сортировка по нескольким столбцам.

4.  **Управление колонками:** Пользователь может настраивать отображение колонок: скрывать/показывать, изменять порядок, регулировать ширину.

5.  **Пагинация:** При большом количестве записей данные разбиваются на страницы, что обеспечивает быструю загрузку и удобную навигацию.

6.  **Экспорт данных:** Готовые данные можно выгрузить в CSV или Excel для дальнейшего анализа.

## Планы по доработке (Roadmap)

Проект активно развивается. В ближайших планах:

- [ ] **Интеграция с серверной пагинацией:** Для работы с действительно большими данными (10 000+ записей) добавить серверную пагинацию и фильтрацию.
- [ ] **Редактирование в ячейках:** Возможность редактировать данные прямо в таблице с автосохранением.
- [ ] **Drag-and-drop для строк:** Изменение порядка записей с помощью перетаскивания.
- [ ] **Сохранение состояния:** Запоминать настройки таблицы (сортировку, фильтры, видимые колонки) в `localStorage`.
- [ ] **Тёмная тема:** Добавить возможность переключения между светлой и тёмной темами оформления.
- [ ] **Мобильное приложение:** Адаптировать интерфейс для комфортной работы на смартфонах с сенсорным управлением.
- [ ] **Unit-тесты:** Повысить покрытие тестами ключевых функций.
